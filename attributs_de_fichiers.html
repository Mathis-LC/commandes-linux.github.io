Commande Utilité
chgrp Permet de changer le groupe propriétaire d'un fichier
chmod Permet de modifier les permissons de dossiers ou de fichiers
chown Change le propriétaire d'un fichier
file Effectue des tests pour déterminer le type du fichier. Cette commande est pratique pour vérifier si un fichier est codé en ASCII avant de l'afficher à l'écran
stat Affiche le contenu des métadonnées d'un fichier
touch Permet de créer un fichier vide
wc Affiche le nombre d'octets, de mots et de lignes d'un fichier
